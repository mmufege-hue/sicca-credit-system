 COMO EXECUTAR
═════════════════════════════════════════════════════════════════════════════════

🌐 OPÇÃO 1: Abrir ficheiro directamente
   ────────────────────────────────────────
   $ open index.html

   Ou no terminal padrão:
   $ xdg-open index.html (Linux)
   $ start index.html (Windows)

🚀 OPÇÃO 2: Servidor HTTP Local (Python 3)
   ────────────────────────────────────────
   $ cd sicca-credit-system
   $ python3 -m http.server 8000
   
   Depois aceda a: http://localhost:8000

📦 OPÇÃO 3: Servidor Node.js
   ────────────────────────────────────────
   $ npx http-server .
   
   Depois aceda a: http://localhost:8080

💻 OPÇÃO 4: VS Code Live Server
   ────────────────────────────────────────
   1. Instale extensão "Live Server"
   2. Clique com botão direito em index.html
   3. "Open with Live Server"
